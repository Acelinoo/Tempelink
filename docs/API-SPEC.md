# Tempelink — API Specification

Version: 1.0.0 (Phase 1)  
Base URL: `/api`  
Format: JSON (`application/json`)  

---

## 1. Global Standards & Headers

### Request Headers
- `Content-Type: application/json`
- `X-Correlation-ID` (Optional): Client-supplied UUID for distributed tracing. Generated by server if absent.

### Response Headers
- `X-Correlation-ID`: Unique tracing identifier attached to every request.
- `X-RateLimit-Limit`: Maximum allowed requests per window.
- `X-RateLimit-Remaining`: Remaining request quota.
- `X-RateLimit-Reset`: Milliseconds until quota window refreshes.

---

## 2. Structured Error Format

All error responses adhere to a uniform structure with both an invariant technical error code and an Indonesian user-friendly message:

```json
{
  "success": false,
  "error": {
    "code": "UNSUPPORTED_PLATFORM",
    "message": "Platform ini belum didukung oleh Tempelink.",
    "correlationId": "f6b9c9d0-2f3b-481b-a5d9-7e5c54b66df2",
    "details": null
  }
}
```

### Technical Error Codes & Status Mappings
| Error Code | HTTP Status | User Message (Indonesian) | Description |
| :--- | :--- | :--- | :--- |
| `INVALID_URL` | 400 | "Link tidak valid. Pastikan format URL sudah benar." | Malformed URL string or disallowed protocol. |
| `UNSUPPORTED_PLATFORM` | 422 | "Platform ini belum didukung oleh Tempelink." | Hostname does not match any registered provider. |
| `UNSUPPORTED_MEDIA` | 422 | "Tipe media pada link ini belum didukung." | URL points to a non-media page (e.g. profile, settings). |
| `PRIVATE_CONTENT` | 403 | "Media bersifat privat atau memerlukan otentikasi." | Target media is not publicly accessible. |
| `CONTENT_UNAVAILABLE` | 404 | "Media tidak ditemukan atau sudah dihapus." | 404 / removed by creator. |
| `RATE_LIMITED` | 429 | "Permintaan terlalu banyak. Silakan tunggu beberapa saat." | Client IP exceeded request threshold. |
| `SSRF_BLOCKED` | 403 | "Permintaan URL ditolak demi alasan keamanan sistem." | Target resolves to loopback, private IP, or cloud metadata. |
| `PROVIDER_UNAVAILABLE`| 503 | "Layanan platform tujuan sedang mengalami gangguan." | External platform upstream outage. |
| `INTERNAL_ERROR` | 500 | "Terjadi kesalahan internal. Silakan coba lagi nanti." | Unexpected server exception. |

**Description**: Analyzes a media URL, performs SSRF verification, detects platform, and extracts available capabilities.

### 3.2. Initiate Download / Stream Descriptor
**Endpoint**: `POST /api/media/download`  
**Description**: Prepares download delivery for a chosen capability using the server-signed download token.

#### Request Body
```json
{
  "mediaId": "tiktok_123456789",
  "capabilityId": "cap_video_hd",
  "sourceUrl": "https://www.tiktok.com/@creator/video/123456789",
  "downloadToken": "eyJtZWRpYUlkIjoidHQ...HMAC_SIGNATURE"
}
```

#### Success Response (`200 OK`)
```json
{
  "success": true,
  "data": {
    "downloadType": "direct_url",
    "downloadUrl": "https://cdn.tiktok.example/stream/...",
    "filename": "tiktok_123456789_1080p.mp4",
    "mimeType": "video/mp4",
    "expiresAt": "2026-09-21T13:30:00.000Z"
  }
}
```

### 3.3. Direct Browser Media Download
**Endpoint**: `GET /api/media/download?token={signedToken}`  
**Description**: Direct HTTP 302 redirect or stream attachment delivery for verified, unexpired tokens.

#### Query Parameters
- `token`: Cryptographically signed HMAC-SHA256 token generated by `/api/media/resolve`.

#### Success Response (`302 Found`)
- **Status**: `302 Found`
- **Location**: `https://cdn.platform.example/stream/...` (SSRF-verified target URL)
- **Headers**:
  - `Content-Disposition`: `attachment; filename="tiktok_7123456789_standard.mp4"` (RFC 6266 / RFC 5987 formatted)
  - `Cache-Control`: `no-store, no-cache, must-revalidate, proxy-revalidate`
  - `Pragma`: `no-cache`
  - `Expires`: `0`
  - `X-Content-Type-Options`: `nosniff`
  - `X-Correlation-ID`: `corr_id`

#### Error Response (`403 Forbidden` / `410 Gone` / `400 Bad Request`)
```json
{
  "success": false,
  "error": {
    "code": "SSRF_BLOCKED",
    "message": "Tanda tangan token download tidak sah (forged token).",
    "correlationId": "corr_id"
  }
}
```
